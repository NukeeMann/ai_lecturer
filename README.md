# AI Lecturer

A single-user, locally-hosted web app for studying interactive AI-generated lessons. Lessons are produced by the `ralph` agent chain (course-spec → clarification → lesson generation); the webapp renders the resulting course JSON, tracks per-lesson progress on disk, and can drive a ralph run from its course-creation wizard.

## Stack

- Next.js 16 (App Router) · React 19 · TypeScript (strict)
- Tailwind CSS v3
- shadcn/ui (initialized; components added per-story)
- Vitest · Pyodide (for in-browser Python widgets)

## Run

```bash
npm install
npm run dev            # http://localhost:3000
npm run build          # production build
npm run start          # serve the built app
npm run lint           # eslint
npm run typecheck      # tsc --noEmit
npm test               # vitest
npm run build:schemas  # regenerate src/widgets/schemas/*.json from each widget's Zod schema
```

## Quick start (Windows, clean machine)

A one-shot PowerShell setup script lives at `setup.ps1` in the repo root. It installs Node.js LTS via `winget` (if missing), runs `npm install`, installs the Claude Code CLI globally, opens an interactive `claude` login prompt (you type credentials live in the terminal), and finally starts `npm run dev`.

Bootstrap on a fresh Windows 10/11 box (run in PowerShell):

```powershell
# 1. Prerequisites: Git + GitHub CLI (skip any you already have)
winget install --id Git.Git -e --accept-source-agreements --accept-package-agreements
winget install --id GitHub.cli -e --accept-source-agreements --accept-package-agreements

# 2. Authenticate to GitHub (interactive — choose HTTPS + browser login)
gh auth login

# 3. Clone the (private) repo and enter it
gh repo clone NukeeMann/ai_lecturer
cd ai_lecturer

# 4. Run the setup script
#    First time only: allow local scripts in this session
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\setup.ps1
```

The script is idempotent — re-run it any time. Useful flags:

- `.\setup.ps1 -SkipLogin` — already logged into Claude Code
- `.\setup.ps1 -SkipDev` — install/login only, don't start the dev server
- `.\setup.ps1 -SkipLogin -SkipDev` — silent install only

Any step that needs credentials (`gh auth login`, `claude /login`) prompts you live in the same terminal — no env-vars or secrets files required.

## Layout

- `src/app/` — Next.js routes (incl. `/create` wizard) and `src/app/api/` server endpoints
- `src/components/` — shared UI (with `ui/` from shadcn)
- `src/widgets/` — per-widget lesson components: Theory, Quiz, Code, CodeCloze, Demo, Sandbox, Histogram, DataTable, DragMatch, ParametricExplorer, PlotImage, Video, Custom. See `src/widgets/README.md` for the contract.
- `src/lib/schemas/` — course/lesson/courseSpec/progress Zod schemas, shared with the agent chain
- `src/widgets/schemas/` — JSON-schema mirrors of each widget's Zod schema (generated by `npm run build:schemas`, consumed by ralph skills)
- `src/lib/server/` — server-only modules (atomic file I/O, course/progress persistence, ralph-runner)
- `src/lib/wizard/` — course-spec wizard helpers (clarification questions, downstream-stage invalidation)
- `scripts/ralph/` — the offline agent loop: `ralph.sh` orchestrator, stage skills, and the working PRD
- `docs/widgets.md` — canonical widget catalog used by the ralph lesson-authoring skills
- `courses/` — generated and example courses (incl. `widget-dev-guide` and a per-widget `*-test`)

Generated courses live under `./courses/<slug>/`; per-user progress is stored at `~/.ai-lecturer/progress.json`.

## Static HTML export

A course can be exported as a self-contained ZIP of pre-rendered `.html` files via the dashboard's three-dots menu (`Export as static HTML`). The exported folder runs on any static host — there is no Node.js / Next.js server requirement. Code widgets remain interactive: a small `assets/pyodide-loader.js` shim loads Pyodide from the jsDelivr CDN on first use.

**Internet access required**: viewing an exported course needs network access on first load so the browser can fetch Pyodide from `https://cdn.jsdelivr.net/pyodide/`. An offline-bundled Pyodide build is explicitly out of scope (it would balloon every export by 10 MB+).

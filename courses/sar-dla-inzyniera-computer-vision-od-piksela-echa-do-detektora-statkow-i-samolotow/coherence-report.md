## Prerequisite Order

- `amplituda-faza-i-speckle-ziarnistosc-ktora-nie-jest-szumem-gaussowskim` uses the term **GRD** in its task and hidden tests ("produkt GRD jest już mocno zmultilookowany", "ENL wody (GRD juz zmultilookowany)"), and `despeckling-w-praktyce-lee-frost-refined-lee-i-nl-means-beforeafter` uses it again ("dla kafelka GRD o ENL≈30"), but the **SLC vs GRD** distinction is only defined in `od-sceny-do-kafelka-grd-multilooking-geokodowanie-i-terrain-correction` (module 3). For a CV engineer entering SAR data this acronym is not common knowledge, and the course itself treats it as needing a definition. Add a one-line gloss (or a forward-pointer) at first use in `amplituda-faza-...`.

- `detekcja-statkow-i-samolotow-cfar-jako-pre-detektor-klasyfikator-cnn` reports **czułość / precyzja / F1** as already-understood metrics in its bar-chart section ("czułość 0.95, precyzja tylko 0.40, F1 0.56 → 0.91"), but precision, recall, F1 (and IoU) are formally introduced with definitions and symbol glosses only two lessons later in `metryki-i-odpornosc-map-f1-per-klasa-oraz-model-data-agnostic`. This is likely fine for the senior-CV audience, but it is inconsistent with the course's own decision to introduce these from scratch in the later lesson; a brief forward-pointer in `detekcja-...` would remove the seam.

## Redundancy

- `detekcja-statkow-i-samolotow-cfar-jako-pre-detektor-klasyfikator-cnn` and `transfer-learning-i-augmentacja-sar-klasyfikacja-celow-na-chipach` (back-to-back in module 5) both explain **why ImageNet/RGB transfer fails on SAR** from scratch, with a nearly identical list (one channel vs three RGB, multiplicative speckle ≠ Gaussian, dB normalization instead of ImageNet mean/std, small point targets) and a near-duplicate quiz (same three correct reasons plus a "can't learn grayscale / always lower resolution" distractor). Neither acknowledges the other. There is a real difference in angle — `detekcja-...` is detector-oriented (anchors, DETR queries) and `transfer-...` is backbone/classifier-oriented (freeze early layers) — so pick one as the canonical "why transfer breaks" explanation and have the other cite and deepen it rather than re-derive it.

- Minor: the reasoning for **masking land before running CFAR** is fully re-derived in the `capstone-surowa-scena-sar-detekcje-statkowsamolotow-raport` quiz (`quiz-kolejnosc`) in the same terms as `cfar-krok-po-kroku-adaptacyjny-prog-ktory-wykrywa-statki-na-morzu` (`pulapki-cfar`: bright land inflates μ and σ in the background ring), without a "recall from…" pointer. As a capstone this repetition is plausibly intentional reinforcement, so this is low priority.

## Notation Consistency

- Code identifier language drifts across the course. The first two lessons name functions in Polish — `maska_silnych_ech` / `udzial_silnych_ech` (`radar-to-nie-kamera-wasne-oswietlenie-zamiast-swiata-otoczenia`) and `cien_radarowy` (`geometria-sceny-bez-trygonometrii-range-azimuth-layover-i-shadow`) — while every later lesson uses English function names: `detect_targets` (`detekcja-statkow-i-samolotow-cfar-jako-pre-detektor-klasyfikator-cnn`), `iou` / `precision_recall_f1` (`metryki-i-odpornosc-map-f1-per-klasa-oraz-model-data-agnostic`), `speckle_jitter`, `run_capstone`. Variable names stay Polish throughout (`woda`, `prog`, `okno`). A learner moving between widgets sees the function-naming convention flip language; pick one convention.

- The same "local mean in a window" is written **$\bar I$** in the Lee filter formula in `despeckling-w-praktyce-lee-frost-refined-lee-i-nl-means-beforeafter` ($\hat I = \bar I + W(I-\bar I)$) but **$\mu$** in the CFAR threshold in `cfar-krok-po-kroku-adaptacyjny-prog-ktory-wykrywa-statki-na-morzu` ($T = \mu + \alpha\sigma$), even though both denote the local window mean of intensity. Likewise, pixel **amplitude** is $A$ in `amplituda-faza-i-speckle-ziarnistosc-ktora-nie-jest-szumem-gaussowskim` ($I = A^2$) but $x(i,j)$ in `transfer-learning-i-augmentacja-sar-klasyfikacja-celow-na-chipach` (speckle-jitter). Both drifts are mild and partly explained by context (ML input conventionally $x$), but a one-line note tying $\bar I \equiv \mu$ and $x \equiv A$ at the points of reuse would prevent confusion.

- **Learnings for future iterations:**
  - **React onWheel is passive — can't preventDefault.** When you need a scrolling element to consume vertical-wheel input and stop the page from scrolling, attach `wheel` via `addEventListener('wheel', handler, { passive: false })` inside a `useEffect`, not via React's `onWheel` prop. React's synthetic event has the wheel listener attached as passive in modern versions, so calling `e.preventDefault()` in JSX is silently ignored.
  - **Native scrollbar removal recipe:** put `scrollbar-width: none` on the element (Firefox + modern Chromium) plus a `selector::-webkit-scrollbar { display: none; width: 0; height: 0 }` rule for legacy WebKit. Inline-style `scrollbar-width` works too, but the `::-webkit-scrollbar` pseudo-element is not stylable from inline styles, so a CSS class is the right home.
  - **Edge-detect pattern for L/R arrow buttons.** Listen to `scroll` (passive) on the track and use a `ResizeObserver` to refresh on layout changes.

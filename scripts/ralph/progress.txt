## Codebase Patterns
- Repo dir is named `US-001` (capitalized) → cannot run `create-next-app .` directly because npm rejects capital letters in package names. Workaround: scaffold into a temp dir (e.g. `/tmp/ai-lecturer-scaffold`), then copy files into the worktree (skip the inner `.git`), and set the package name in `package.json` manually.

- Theme/accent/density are switched by `data-theme` / `data-accent` / `data-density` attributes on `<html>` (defaults: `light` / `default` / `comfortable`). Selectors in tokens.css are scoped to `:root[data-theme=…]` etc. — adding new variants means adding a new `:root[data-…="…"]` block, not a new file.

- **`PythonError` shape (Pyodide 0.26).** A Pyodide exception thrown out of `runPythonAsync` is a `PythonError` (`err.constructor.name === 'PythonError'`, `err instanceof Error === true`). The headline `<Type>: <msg>` is the LAST non-empty line of `err.message`. That catches drift if a future edit narrows the trigger list (e.g. drops "what's the right option" and breaks quiz-mode override) without needing a real model call. The dominance test (`overrideIndex < winsIndex`) protects against accidental rule reordering during reformatting.
  - Multi-line string literals: avoid `'line1\\n\\nline2\\n- bullet'` walls — hard to read, hard to diff. The `[..., ''].join('\n')` array pattern is cleaner and lets reviewers see the actual prompt structure. Keep it for any prompt > 2 lines.

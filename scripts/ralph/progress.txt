  - `set -u` plus `local foo=$bar` inside a function: the local declaration runs even when `bar` is being read — initialize defaults FIRST (`local effective_timeout_sec="$TASK_TIMEOUT_SEC"`), then conditionally override. This avoids "unbound variable" if a later code path reads the local before the conditional fires.
  - `local` declarations don't allow command substitutions in the same line to capture exit codes via pipefail — `local x=$(cmd | jq …)` always returns 0. Existing code splits these into `local x` then `x=$(...)` for a reason. Followed that pattern for `story_timeout_raw`.
